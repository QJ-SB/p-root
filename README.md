# ***ROOT***

ROOT 是用于管理、设计、重构和验证 AI 协作项目范式的根项目。

本文件是 ROOT 面向人类的项目入口，用于快速理解项目为什么存在、负责什么以及去哪里查看进一步信息。

它不承担 AI 行为指令或能力路由职责。AI 的项目入口统一由根目录中的 `project-instruction.md` 承担；因此，本文件默认不装载进 GPT Project Files 或同类 AI 项目文件环境。

## `Why:`

> AI 时代的主要瓶颈正在从“产出能力”转向“人类的 attention 与 review bandwidth”。

> 当项目可以被 AI 快速创建、扩展和优化时，也更容易出现：

```text
* 项目职责持续膨胀
* 架构和协议过度细化
* 状态、checkpoint 与文档重复
* 为潜在需求提前建设
* 人类审核成本超过实际产出价值
```

ROOT 的目的，是建立并持续验证一套**简单、稳定、低维护成本的 AI 协作项目范式**。

## `Positioning:`

> ROOT 负责：

```text
* 定义通用项目设计原则
* 设计和维护最小项目骨架
* 辅助创建、审查和重构其他项目
* 从真实项目实践中提炼可复用原则
```

ROOT **不作为其他项目的中央运行系统**。

不同项目彼此独立，不需要认识 ROOT 或其他项目。跨项目的信息选择、传递与组合由人类负责。

## `Principles:`

> ROOT 默认遵循以下原则：

```text
* 能删就不加.
* 能合并就不拆。
* 能让 AI 判断就不写规则
* 能开始产出就停止造系统
```

优先建立能够稳定工作的 **Minimal Vertical Slice**。

只有真实使用中反复出现的问题，才值得进一步结构化、优化或扩展。
